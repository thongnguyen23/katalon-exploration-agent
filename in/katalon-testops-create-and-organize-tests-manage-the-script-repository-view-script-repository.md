# <a id="concept-7714" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>View script repository

<p xmlns="http://www.w3.org/1999/xhtml" className="p">A repository is a centralized storage location for all your testing assets, enabling better collaboration, version control, and accessibility for team members.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="p">Script repositories are organized in the <span className="ph uicontrol">Test Directory</span>. To view your connected repositories in TestOps, you can either: <ul className="ul"><li className="li">Go to Tests &gt; Test Cases</li><li className="li">Go to Tests &gt; Test Suites</li></ul></div>
<p xmlns="http://www.w3.org/1999/xhtml" className="p">The <span className="ph uicontrol">Test Directory</span> acts as the primary hub for creating and managing test cases and test suites, all of which are displayed in a list format. </p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">It also houses Git repositories and Katalon Cloud storage.</p>
