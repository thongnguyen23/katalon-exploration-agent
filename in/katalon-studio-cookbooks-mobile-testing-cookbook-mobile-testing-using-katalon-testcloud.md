# <a id="concept-9903" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Mobile testing using  <span xmlns="http://www.w3.org/1999/xhtml" className="ph">Katalon TestCloud</span> 

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">Learn how to create and execute a mobile test using <span className="ph">Katalon TestCloud</span>.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p"><span className="ph">Katalon TestCloud</span> is a test automation service that allows you to run tests on a wide range of standard browsers and operating systems in the cloud. By using <span className="ph">TestCloud</span>, you can easily configure your mobile testing environments without the need to invest in additional infrastructure.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">When following the mobile testing workflow with  <span className="ph">TestCloud</span>, there are several key steps to complete:</p> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol"><li className="li"><p className="p"><strong className="ph b">Integrate Katalon Studio with <span className="ph">TestCloud</span></strong>: Upload your mobile application to <span className="ph">TestCloud</span> to begin the testing process.</p>   </li><li className="li"><p className="p"><strong className="ph b">Create and record a test case</strong>: Create a new mobile test case using the Mobile Recorder. For more information about using Mobile Recorder in Katalon Studio, see: <a className="xref" href="/katalon-studio/create-test-cases/create-a-new-test-case-in-katalon-studio">Create a new test case in <span className="ph">Katalon Studio</span></a>.</p>   </li><li className="li"><p className="p"><strong className="ph b">Create a test suite or test collection</strong>: Group related test cases into a suite or collection for organized testing.</p>   </li><li className="li"><p className="p"><strong className="ph b">Run mobile tests on a TestCloud environment</strong>: Execute the tests with different modes to suit your testing needs:</p><ol className="ol" type="a"><li className="li"><p className="p">Parallel mode: Run multiple tests simultaneously to save time.</p></li><li className="li"><p className="p">Sequential mode: Execute tests one after the other for thorough examination.</p></li></ol></li></ol> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Before you begin recording, ensure your testing environment is properly set up. Refer to the following topics for more information: <a className="xref" href="/katalon-testcloud/supported-environments-for-katalon-testcloud">Supported environments for Katalon TestCloud</a>.</p>

## <a id="concept-ibv9p3td" class="anchor_top_offset"/>Run mobile native application tests on <span xmlns="http://www.w3.org/1999/xhtml" className="ph">TestCloud</span> 

<p xmlns="http://www.w3.org/1999/xhtml" className="p"><span className="ph">TestCloud</span> allows you to perform automated tests on mobile native applications. You can upload a mobile application and tests developed locally in <span className="ph">Katalon Studio</span> to <span className="ph">TestOps</span>, and then use <span className="ph">TestCloud</span> to orchestrate test executions without having to set up local emulators or simulators.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">This guide shows you how to perform mobile native application testing on <span className="ph">TestCloud</span>.</p>

<div xmlns="http://www.w3.org/1999/xhtml" className="p"><ul className="ul"><li className="li"><p className="p">An active <span className="ph">Katalon TestCloud</span> subscription or trial.</p></li><li className="li"><p className="p">A mobile application file in <kbd className="ph userinput">.apk</kbd> or <kbd className="ph userinput">.aab</kbd> format (for Android), or in <kbd className="ph userinput">.ipa</kbd> format (for iOS).</p></li><li className="li"><p className="p">A mobile test project configured in <span className="ph">TestOps</span>. </p><ul className="ul"><li className="li"><p className="p">To set up a sample project for iOS application testing, see <a className="xref" href="/katalon-studio/cookbooks/mobile-testing-cookbook/utilizing-sample-mobile-tests-projects#id-frdh4dhp">Sample iOS mobile project in <span className="ph">Katalon Studio</span></a>.</p></li><li className="li">To set up a sample project for Android application testing, see <a className="xref" href="/katalon-studio/cookbooks/mobile-testing-cookbook/utilizing-sample-mobile-tests-projects#id-cm6opauk">Sample Android mobile project in Katalon Studio</a> .</li></ul></li><li className="li"><p className="p">For Android hybrid mobile applications, refer to the following topic: <a className="xref" href="/katalon-studio/cookbooks/mobile-testing-cookbook/hybrid-mobile-apps-testing-in-katalon-studio">Capture elements in hybrid Android apps</a>.</p></li></ul></div>

### <a id="concept-0sga2tho" class="anchor_top_offset"/>Use TestCloud private mobile devices

<div xmlns="http://www.w3.org/1999/xhtml" className="p">TestCloud provides you with a wide range of real mobile devices, in both iOS and Android, to execute mobile tests. With TestCloud private mobile devices, you can have more control over your test devices compared to shared devices:<ul className="ul"><li className="li"><strong className="ph b">Non-shared environment</strong>: Private devices are dedicated to your organization, ensuring high availability and consistent performance.</li><li className="li"><strong className="ph b">Enhanced data privacy</strong>: With complete control over the data stored on the device, you reduce the risk of exposing this data to other users or third parties.</li><li className="li"><strong className="ph b">Session retention</strong>: Private devices come with longer session retention, allow you first configure device functionalities and later perform multiple tests without having to reconfigure from scratch.</li></ul></div>
<p xmlns="http://www.w3.org/1999/xhtml" className="p">With a TestCloud private device subscription, you can perform tests on private mobile devices just as you would on shared devices. See: <a className="xref" href="/katalon-testcloud/mobile-native-app-testing/mobile-native-app-testing-with-testcloud">Run mobile native application tests</a>.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">When selecting devices in the <span className="ph uicontrol">Configure Test Environment</span> section, you can find your private mobile devices labeled with their UDID.<img className="image" width={700} src={useBaseUrl("/c1cab5bd-e1e2-4a86-9de4-ca906caf606d/TestCloud_test_scheduler_private_mobile_device.png")} alt="Configure test environment for test suite, device with UDID tag" /></p>
