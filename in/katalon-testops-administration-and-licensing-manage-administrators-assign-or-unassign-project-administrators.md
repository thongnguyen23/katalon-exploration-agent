# Assign or unassign Project Administrators
Learn how you can assign or unassign Project-level Administrators in Katalon TestOps.

## Prerequisites

- Make sure you are an Account Admin or possess the relevant permissions. Go to [roles](/katalon-testops/administration-and-licensing/manage-systems/permissions/about-roles) or [permissions](/katalon-testops/administration-and-licensing/manage-systems/permissions/about-permissions) for more information or learn how to [assign an Account Admin here](/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-account-administrators).

---

Assign or unassign Project Administrators directly from your Project's settings.

## View Project Admins

1. Within your Project, Go to **Settings > General**. 

The Project General page appears.

<img src="https://tw-cdn.katalon.com/katalon-testops/Settings/General/Settings Project General Page 2.png" alt="Your Account information in Katalon TestOps" width="1080"/>

<br/>

2. Click on the dropdown menu in the **Project Admin** section.

## Assign or unassign an Admin

3. Select the name of the user you want to assign as a Project Admin.

:::note

- You can unassign an admin by deselecting their name from the dropdown.

:::

4. Click **Save**.

## Results

The page refreshes and a notification appears to confirm the assignment.
