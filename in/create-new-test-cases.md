# <a id="task-8604" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Create new test cases

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This document shows you how to create a test case without steps in it. </p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Create your test case by clicking on <span className="ph uicontrol">+ Create</span> within the Test Directory.</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to Tests &gt; Test Cases in the sidebar. The Test Directory page appears.</span></li><li className="li step stepexpand"><span className="ph cmd">Click on the <span className="ph uicontrol">+ Create</span> button.</span></li><li className="li step stepexpand"><span className="ph cmd">From the dropdown menu, select <span className="ph uicontrol">Test Case</span>.</span></li><li className="li step stepexpand"><span className="ph cmd">A dialog box appears. Fill out the following information:</span><div className="itemgroup info"><ul className="ul"><li className="li"><span className="ph uicontrol">Name</span> (required): Input the label for your test case.</li><li className="li"><span className="ph uicontrol">Description</span> (optional): Input details about your test case.</li><li className="li"><span className="ph uicontrol">Precondition</span> (optional): List the prerequisites for your test case.</li></ul></div></li><li className="li step stepexpand"><span className="ph cmd">Click <span className="ph uicontrol">Create</span>.</span><ul className="ul choices"><li className="li choice">Alternatively, click on "Save &amp; Create Another" to immediately input information for an additional test case without navigating away from the current screen.</li></ul></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">A toast notification confirms the successful creation of your test case. Additionally, the newly created test case appears in the list within the <span className="ph uicontrol">Test Directory</span> page.</section>
