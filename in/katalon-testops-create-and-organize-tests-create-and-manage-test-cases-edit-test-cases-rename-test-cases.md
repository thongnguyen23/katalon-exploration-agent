# <a id="task-3278" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Rename test cases

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This document shows you how to rename test cases.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Click on a test case's three-dot menu from the <span className="ph uicontrol">Test Directory</span> and select <span className="ph uicontrol">Rename</span>.</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step"><span className="ph cmd">Go to <span className="ph uicontrol">Tests</span> &gt; <span className="ph uicontrol">Test Cases</span>.</span></li><li className="li step"><span className="ph cmd">Click on the three-dot menu of the test case you would like to rename. It is found at the rightmost column and shows upon hovering.</span></li><li className="li step"><span className="ph cmd">Click  <span className="ph uicontrol">Rename</span>.</span></li><li className="li step"><span className="ph cmd">Type the new name in the displayed dialog box.</span></li><li className="li step"><span className="ph cmd">Click <span className="ph uicontrol">Save</span>.</span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">A toast notification confirms that you've renamed your test case.</section>
