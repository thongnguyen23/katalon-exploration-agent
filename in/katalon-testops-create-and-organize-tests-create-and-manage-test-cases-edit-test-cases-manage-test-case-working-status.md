# <a id="task-9530" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Manage test case working status

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This document shows you how to change the working status of your test case.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Click on the status dropdown from the test case's details page and selects its corresponding status.</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step"><span className="ph cmd">Navigate to the test case you would like to change the status of.</span></li><li className="li step"><span className="ph cmd">Click on the test case. The test case's details appear.</span></li><li className="li step"><span className="ph cmd">Click on the status dropdown. Select from the five available options: <span className="ph uicontrol">Draft</span>, <span className="ph uicontrol">Ready to review</span>, <span className="ph uicontrol">In review</span>, <span className="ph uicontrol">Published</span>, and <span className="ph uicontrol">Inactive</span>.</span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">After selected, the working status is updated automatically.</section>
