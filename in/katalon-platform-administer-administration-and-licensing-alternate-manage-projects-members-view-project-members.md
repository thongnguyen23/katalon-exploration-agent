# <a id="task-8804" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>View Project Members

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This document shows you how you can view the complete list of Members that are working on a Project. </p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li"><p className="p">Make sure you are a Project Admin or possess the relevant permissions. Go to <a className="xref" href="/katalon-testops/administration-and-licensing/manage-systems/permissions/about-roles">roles</a> or <a className="xref" href="/katalon-testops/administration-and-licensing/manage-systems/permissions/about-permissions">permissions</a> for more information or learn how to <a className="xref" href="/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-project-administrators">assign a Project Admin here</a>. </p></li></ul></div>
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">View your Project's Members by going to <span className="ph menucascade"><span className="ph uicontrol">Admin Settings</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Project</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Members</span></span>.</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph menucascade"><span className="ph uicontrol">Admin Settings</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Project</span></span>. You can find Admin Settings at the upper right corner of the page, indicated by a cog icon.<br/>The <span className="ph uicontrol">General</span> tab appears by default. </span></li><li className="li step stepexpand"><span className="ph cmd">Go to the <span className="ph uicontrol">Members</span> tab. The Member directory is displayed, with all Members listed.</span><div className="itemgroup info"><img className="image" width={700} src={useBaseUrl("/a5488473-5048-446b-9bf2-616fb0a5081f/TO3GA1_Members_Directory_Censored.png")} alt="The Member directory displays a list of all users in a Project in Katalon TestOps." /></div></li><li className="li step stepexpand"><span className="ph cmd">Optionally, you could add filters to search for a specific Member more easily. You can do any of the following:</span><div className="itemgroup info"><ul className="ul choices"><li className="li choice">Input their name or email into the search bar</li><li className="li choice">Filter for the Organization they belong to </li><li className="li choice">Filter for the roles they possess</li><li className="li choice">Filter for licenses they possess</li><li className="li choice">Filter for their status in the Project: active, pending, or inactive </li><li className="li choice">Click on <span className="ph uicontrol">Reset Filter </span>to remove search filters </li></ul></div></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">The Member directory immediately displays a list of users based on your chosen parameters.</section>
