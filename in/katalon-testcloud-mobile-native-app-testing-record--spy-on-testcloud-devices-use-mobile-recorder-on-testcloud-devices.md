# <a id="concept-vrd4q2fx" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Use Mobile Recorder on TestCloud devices

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">The Mobile Recorder utility in Katalon Studio allows you to create automated test cases for mobile applications. </p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Starting from Katalon Studio  9.5.0, you can use TestCloud mobile devices for recording and playback. This feature eliminates  the need for complex local setups and makes it easier for users with minimal coding experience to conduct mobile testing.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">After you  upload your app to TestOps, you can start   recording objects on a TestCloud mobile device.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Here's a demo video of using mobile recorder on TestCloud devices:<object data="https://fast.wistia.com/embed/medias/dcz81c669d" height={450} width={700}> </object></p> 

## Requirements

<ul xmlns="http://www.w3.org/1999/xhtml" className="ul"><li className="li"><span className="ph">Katalon Studio Enterprise (KSE)</span> version 9.5.0 onwards.</li><li className="li">A  <span className="ph">TestCloud</span> Mobile Native App testing subscription.</li></ul> 

## <a id="task-4am8w1ga" class="anchor_top_offset"/>Record objects on a TestCloud device
