# <a id="task-6526" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Rename a Project

<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li"><p className="p">Make sure you are a Project Admin or possess the relevant permissions. Go to <a className="xref" href="/katalon-testops/administration-and-licensing/manage-systems/permissions/about-roles">roles</a> or <a className="xref" href="/katalon-testops/administration-and-licensing/manage-systems/permissions/about-permissions">permissions</a> for more information or learn how to <a className="xref" href="/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-project-administrators">assign a Project Admin here</a>. </p></li></ul></div>
<section xmlns="http://www.w3.org/1999/xhtml" className="section context"><p className="p">Rename an Organization via the Organization Management tab in Organization.</p></section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step"><span className="ph cmd">Go to <span className="ph menucascade"><span className="ph uicontrol">Admin Settings</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Organization</span></span>. You can find Admin Settings at the upper right corner of the page, indicated by a cog icon.<br/>The Organization Management tab appears by default. </span></li><li className="li step"><span className="ph cmd">Hover over a Project's name. The <span className="ph uicontrol">Edit Name</span> button appears; it is a pencil icon. Click on it.</span></li><li className="li step"><span className="ph cmd">Enter the new name and click on the check. </span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">You have renamed your Project.</section>
