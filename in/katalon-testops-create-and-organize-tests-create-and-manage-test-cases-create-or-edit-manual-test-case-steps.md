# <a id="task-2553" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Create or edit manual test case steps

<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li">You have created a test case. See <a className="xref" href="/katalon-testops/create-and-organize-tests/create-and-manage-test-cases/create-new-test-cases">Create new test cases</a>.</li><li className="li"><p className="p">You must have either the Test Lead or Tester role. </p></li></ul></div>
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Input manual steps by going to a test case's detail page typing in the <span className="ph uicontrol">Steps</span> section.</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph uicontrol">Tests</span> &gt; <span className="ph uicontrol">Test Cases</span> in the sidebar. The <span className="ph uicontrol">Test Directory</span> page appears.</span></li><li className="li step stepexpand anchor_top_offset" id="task-2553__svg-step-3"><span className="ph cmd">Click on the name of the test case you would like to add steps to.</span><div className="itemgroup info">The test case's details appear. It is automatically tagged as <span className="ph uicontrol">Manual</span>.</div></li><li className="li step stepexpand anchor_top_offset" id="task-2553__svg-step-1"><span className="ph cmd">Optionally, input customization data into the following fields:</span><div className="itemgroup info"><ol className="ol" type="a"><li className="li"><p className="p">Select the working status. It is set to <span className="ph uicontrol">Draft</span> by default. </p></li><li className="li"><p className="p">Input a test case description. </p></li><li className="li"><p className="p">Input pre-conditions or requirements that must be met before the test case is executed.</p></li></ol></div></li><li className="li step stepexpand anchor_top_offset" id="task-2553__svg-step-2"><span className="ph cmd">Scroll down to the <span className="ph uicontrol">Steps</span> section and type or paste your steps in as follows:</span><div className="itemgroup info"><ol className="ol" type="a"><li className="li"><p className="p"><span className="ph uicontrol">Description</span>: Detaill the action that needs to be done. </p></li><li className="li"><p className="p"><span className="ph uicontrol">Expected results</span>: Define the success criteria based on the result of the action.</p></li><li className="li"><p className="p"><span className="ph uicontrol">Test Data</span>: Optionally input additional information about the step. </p></li></ol><div className="note tip note_tip"><span className="note__title">Tip:</span> <ul className="ul"><li className="li">You can copy the test steps from a spreadsheet and paste directly to the section.</li><li className="li"><p className="p">CTRL+Z or CMD+Z to undo an action up to 20 times. </p></li><li className="li"><p className="p">A cell can fit multiple lines of wrapped text.</p></li></ul></div></div></li><li className="li step stepexpand"><span className="ph cmd">You can further edit your test steps directly by clicking on the test steps' numbers and selecting any of the following functions from the pop-up menu. In order, they are: </span><div className="itemgroup info"><ul className="ul"><li className="li"><p className="p">Duplicate: Duplicate one or multiple steps. </p></li><li className="li"><p className="p">Insert above: Inserts a step above. </p></li><li className="li"><p className="p">Insert below: Inserts a step below. </p></li><li className="li"><p className="p">Delete: Delete one or multiple steps. </p></li></ul></div></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">You have created or edited a manual test case's steps. </section>
