# <a id="concept-2849" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Protect user data privacy

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This document provides details on how our data filtering mechanisms work to protect user privacy in Katalon test case generation.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Protecting user privacy is important to us at Katalon. While our <span className="ph">TrueTest</span> Agent tracks user interactions to generate test cases and build a user journey map, we understand that some of this data may be sensitive and could pose privacy concerns. To address this, we have implemented data filtering mechanisms to remove sensitive information before processing the data.</p>

## How data is filtered

<p xmlns="http://www.w3.org/1999/xhtml" className="p"><span className="ph">TrueTest</span> Agent applies several techniques and methods to remove sensitive data from the captured user interaction data. </p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p"><strong className="ph b">Regular expressions</strong></p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">In the beta release of <span className="ph">TrueTest</span>, the agent uses regular expressions to filter data.</p>

<p xmlns="http://www.w3.org/1999/xhtml" className="p"><strong className="ph b">Exclusion list</strong></p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p"><span className="ph">TrueTest</span> Agent allows users to define elements or properties that should be excluded from data capture. This can be done by specifying a CSS class named <code className="ph codeph">katalon-excluded</code> to the UI elements.</p> 

## Data privacy compliance

<div xmlns="http://www.w3.org/1999/xhtml" className="p"><span className="ph">TrueTest</span> Agent is committed to complying with the General Data Protection Regulation (GDPR) and has taken the following actions to ensure data privacy:<ul className="ul"><li className="li"><p className="p"><strong className="ph b">Transparency</strong>: In the closed beta version, <span className="ph">TrueTest</span> Agent transparently informs users about what specific sensitive data is excluded or anonymized via verbal communication as acknowledgment. If users feel their application under test (AUT) does not contain sensitive data, they can try the feature.</p></li><li className="li"><p className="p"><strong className="ph b">User control</strong>: <span className="ph">TrueTest</span> Agent allows users to request a complete deletion of all tracked data and to stop using the feature if they do not trust the data privacy compliance.</p></li><li className="li"><p className="p"><strong className="ph b">Security monitoring</strong>: The internal Security team plays the Data Protection Officer (DPO) role to monitor the data and ensure compliance with GDPR requirements. The team conducts periodic penetration testing and security reviews to identify and address data privacy vulnerabilities.</p></li></ul></div>
<p xmlns="http://www.w3.org/1999/xhtml" className="p">By implementing these measures, <span className="ph">TrueTest</span> Agent is committed to protecting user data and complying with GDPR requirements.</p>
