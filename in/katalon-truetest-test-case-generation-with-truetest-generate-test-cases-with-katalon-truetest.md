title: Generate test cases with Katalon TrueTest
---

Katalon TrueTest is an add-on AI-augmented test automation solution that automatically discovers, models, generates, and maintains user-journey test cases. TrueTest provides a streamlined test generation process, saving time and improving testing efficiency.

[Why did we create TrueTest?](https://katalon-3.wistia.com/medias/7c4aaxpuzs)

[TrueTest: AI-powered Regression Testing Software](https://katalon.com/truetest?wvideo=6sbmcm3f34)

The general workflow of TrueTest is as follows:
<img src="https://tw-cdn.katalon.com/truetest/truetest-diagram.png" width="750" alt="TrueTest general workflow"/>

TrueTest requires installing the TrueTest Agent by adding a Javascript code snippet in the head element of the AUT. After installation, TrueTest Agent will record user interactions as they occur on your site. The agent then produces user journey maps, providing a visual representation of how users navigate and engage with your website.

From the journey data, the Agent generates flows based on what it learns from user interactions. You will then review these flows and decide to generate corresponding test cases. All the generated test artifacts will be stored in a Git-based repository or Katalon Cloud. These test cases can be used for regression testing in a CI/CD pipeline to identify impacts on product functionalities.
