This shows you what the Test Run Status Report is and how to use it.

## Prerequisites

- You must possess the Test Lead or Tester role to perform this action. Go to [Roles](/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-account-administrators) or [Permissions](/katalon-testops/administration-and-licensing/manage-systems/permissions/about-permissions) for more information or learn how to [assign a Project Admin here](/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-project-administrators)

---

This report displays historical test volume and result distribution (passed, failed, etc.) in a stacked bar chart. This visualization allows you to track quality trends across test cycles, with interactive elements for viewing detailed metrics and filtering results by date range. It also displays a list of test runs. Find it in **All Reports > Test Run Status Report**.

## View Test Run Status Report

1. Go to **Reports** > **All Reports** > **Test Run Status Report**. The page displays the Test Run Status Summary chart and the [Test Run list](/katalon-platform/analyze/reports/test-runs). 

<br/>

<img src="https://tw-cdn.katalon.com/katalon-testops/Reports/All Reports/Report Types/Report Test Run Status Report.png" alt="The Test Run Report page in Katalon TestOps." width="1080"/>

<br/>

2. Enter search parameters to filter for specific test runs. You can: 
- Input dates
- Select release: Allows you to filter for test run based on its [associated release](/katalon-testops/plan-and-collaborate/about-the-sprintrelease-timeline).
- Select **Profile**.
- Click on **+ Add more** to view more filters. They are:
    - Select Test Suite
    - Select Test Suite Collection
    - Select Test Run Status
    - Select Executor
    - Select Build Label
    
3. Click on **Apply** to narrow your search or **Reset** to reset the page’s results.
