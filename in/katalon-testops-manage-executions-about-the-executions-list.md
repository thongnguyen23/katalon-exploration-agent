## About the Executions List

The Executions list in Katalon TestOps provides you with a comprehensive view of your ongoing, upcoming, and recently finished test runs, letting you monitor both manual and automated test runs in a single interface. This feature displays critical information about each test execution including: status, duration, test type, or configurations. All this allows yoiu to quickly assess testing activity.

You can quickly identify failed tests that require attention, analyze execution patterns across different time periods, or even access detailed test result information directly from the **View Report** function.
