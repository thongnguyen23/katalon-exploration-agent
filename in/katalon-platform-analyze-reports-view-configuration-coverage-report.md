This shows you what the Configuration Coverage Report is and how to use it.

## Prerequisites

<Reusable />

---

This report combines four powerful visualizations of your test data: 
- A bar chart with coverage percentages (y-axis) plotted against your primary operating systems and browsers (x-axis).
- A summary count of test executions broken down by executed tests and configurations.
- View test execution coverage across operating systems and browsers, displaying the executions count for each.
- A record of your most recent configurations.


This comprehensive view allows you to track test execution metrics across different operating systems and browsers, enabling you to identify coverage gaps, assess testing distribution, and monitor execution trends. Find it in **Reports** > **All Reports** > **Configuration Coverage**.

## View Configuration Coverage

1. Go to **Reports** > **All Reports** > **Configuration Coverage**.

<br/>

<img src="https://tw-cdn.katalon.com/katalon-testops/Reports/All Reports/Report Types/Configuration Coverage Report March 20 2025.png" alt="The Configuration Coverage Report page in Katalon TestOps." width="1080"/>

2. Enter search parameters to filter for specific data. You can:
- Select a date range
- Select an execution type
- Select an operating system

3. Click **Apply** to segregate the data or **Reset** to clear all filters.
