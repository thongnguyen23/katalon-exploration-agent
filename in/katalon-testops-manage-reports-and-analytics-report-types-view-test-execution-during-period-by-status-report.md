This shows you what the Test Execution During Period by Status report is and how to use it.

## Prerequisites

- You must possess the Test Lead or Tester role to perform this action. Go to [Roles](/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-account-administrators) or [Permissions](/katalon-testops/administration-and-licensing/manage-systems/permissions/about-permissions) for more information or learn how to [assign a Project Admin here](/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-project-administrators)

---

This report combines four powerful visualizations of your test data: 
- A stacked bar chart displaying daily test execution results with color-coded breakdown of passed, failed, error, incomplete, blocked, and skipped test counts.
- A pie chart showing the percentage breakdown of all test execution results by status (Passed, Failed, etc.) with corresponding count and percentage values.
- A statistical summary presenting the total count and percentage distribution of test executions categorized as either Manual or Automated.
- A list of test cases. 

This comprehensive view allows you to track quality trends, or identify patterns. Find it **Reports** > **All Reports** > **Test Execution During Period by Status**.

## View Test Execution During Period by Status

1. Go to **Reports** > **All Reports** > **Test Execution During Period by Status**.

<br/>

<img src="https://tw-cdn.katalon.com/katalon-testops/Reports/All Reports/Report Types/Reports All Reports Test Execution During Period By Status March 11 2025 2.png" alt="The Test Execution During Period by Status report page in Katalon TestOps." width="1080"/>

<br/>

2. Enter search parameters to filter for specific data. You can enter:
- Input dates
- Select an Interval
- Select Execution types

3. Click **Apply filters** to segregate the data or **Reset filters** to clear all filters.
