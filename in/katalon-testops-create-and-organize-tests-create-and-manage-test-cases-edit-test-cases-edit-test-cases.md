# <a id="concept-3591" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Edit test cases

<p xmlns="http://www.w3.org/1999/xhtml" className="p">A test case is a specific set of conditions, inputs, and expected outcomes designed to verify a particular aspect of software functionality. </p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Often, multiple test cases are required to verify a function. Customization helps differentiate these test cases or help testers track their working progress more effectively.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">This section shows you how you to edit a test case and its details.</p>
