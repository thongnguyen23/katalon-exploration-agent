# <a id="task-3053" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Create a Project

<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li"><p className="p">Make sure you are a Project Admin or possess the relevant permissions. Go to <a className="xref" href="/katalon-testops/administration-and-licensing/manage-systems/permissions/about-roles">roles</a> or <a className="xref" href="/katalon-testops/administration-and-licensing/manage-systems/permissions/about-permissions">permissions</a> for more information or learn how to <a className="xref" href="/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-project-administrators">assign a Project Admin here</a>. </p></li></ul></div>
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Create a Project via the <span className="ph uicontrol">Organization Management</span> tab in <span className="ph uicontrol">Organization</span>. </section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph menucascade"><span className="ph uicontrol">Admin Settings</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Organization</span></span>.  You can find Admin Settings at the upper right corner of the page, indicated by a cog icon.<br/>The Organization Management tab appears by default. </span></li><li className="li step stepexpand"><span className="ph cmd">Click on <span className="ph uicontrol">+ Create</span>. </span></li><li className="li step stepexpand"><span className="ph cmd">Select Project from the dropdown. </span><div className="itemgroup info"><img className="image" src={useBaseUrl("/c8f6ae88-2969-49fc-a701-074d40183fed/To3B2_Create_Project.png")} alt="The Create Project button in Katalon TestOps Gen 3." /></div></li><li className="li step stepexpand"><span className="ph cmd">The <span className="ph uicontrol">Create Project dialog box</span> appears. Input the requested information: </span><div className="itemgroup info"><ul className="ul"><li className="li">Name</li><li className="li">Description</li><li className="li">Admin: The users you would like to assign as Project Admins.</li><li className="li">Parent organization: The Organization to which you would like to add this project to.</li></ul></div></li><li className="li step stepexpand"><span className="ph cmd">Click <span className="ph uicontrol">Create</span>. </span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">A notification confirms that you've created your Project. It is immediately displayed in the organization directory.<p className="p">You can also navigate to your Projects from the dropdown menu on the upper left of the screen. <img className="image" width={500} src={useBaseUrl("/bfccc10e-d26c-4ecb-9e47-63a7636e5177/TO3G1_Project_Menu.png")} alt="The dropdown to access your Projects in Katalon TestOps Gen 3." /></p></section>
