# <a id="task-776" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Add a Project description

<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li"><p className="p">Make sure you are a Project Admin or possess the relevant permissions. Go to <a className="xref" href="/katalon-testops/administration-and-licensing/manage-systems/permissions/about-roles">roles</a> or <a className="xref" href="/katalon-testops/administration-and-licensing/manage-systems/permissions/about-permissions">permissions</a> for more information or learn how to <a className="xref" href="/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-project-administrators">assign a Project Admin here</a>. </p></li></ul></div>
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Add a Project description via the Organization Management tab in Organization.</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step"><span className="ph cmd">Go to <span className="ph menucascade"><span className="ph uicontrol">Admin Settings</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Organization</span></span>. You can find Admin Settings at the upper right corner of the page, indicated by a cog icon.<br/>The Organization Management tab appears by default. </span></li><li className="li step"><span className="ph cmd">Hover over the second column labeled <span className="ph uicontrol">Desc</span> within the row of the project you'd like to edit. </span></li><li className="li step"><span className="ph cmd">Click on the edit icon.</span></li><li className="li step"><span className="ph cmd">Enter a description and click on the tick once done. </span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result"><p className="p">You have added a description to your Project.</p><p className="p">Hovering over the truncated description displays a tooltip that shows the entire description.</p></section>
