# <a id="task-887" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Upload an application

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">TestCloud allows you to perform automated tests on mobile native applications. You can upload a mobile application and tests developed locally in Katalon Studio to TestOps, and then use TestCloud to orchestrate test executions without having to set up local emulators or simulators.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li">An active Katalon TestCloud mobile native app subscription.</li><li className="li">A mobile application file in .apk or .aab format (for Android), or in .ipa format (for iOS).</li><li className="li">A mobile test project configured in TestOps.
      <ul className="ul"><li className="li">To set up a sample project for iOS application testing, see <a className="xref j-external-link" href="https://docs.katalon.com/katalon-studio/get-started/sample-projects/mobile/sample-ios-mobile-project-in-katalon-studio#id_1" target="_blank">Open the sample iOS test project</a>.</li><li className="li">To set up a sample project for Android application testing, see <a className="xref j-external-link" href="https://docs.katalon.com/katalon-studio/get-started/sample-projects/mobile/sample-android-mobile-project-in-katalon-studio#id_1" target="_blank">Open the sample Android test project</a> .</li></ul></li></ul></div>
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Go to the Application Repository to upload your app. </section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph menucascade"><span className="ph uicontrol">Resources</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Application</span></span>. The Application Repository appears. </span></li><li className="li step stepexpand"><span className="ph cmd">Click on <span className="ph uicontrol">Upload Application</span>. </span></li><li className="li step stepexpand"><span className="ph cmd">In the upload application dialog box, click <span className="ph uicontrol">Choose Files</span> and select the application you want to upload. </span><div className="itemgroup info"><div className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li">The Application Repository supports uploading application files in:             <ul className="ul"><li className="li">.apk</li><li className="li">.aab</li><li className="li">.ipa</li></ul></li><li className="li">The size limit for the uploaded application is 500MB.</li></ul></div></div></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">Your application is successfully uploaded to the Application Repository. It now shows within your application list. </section>
