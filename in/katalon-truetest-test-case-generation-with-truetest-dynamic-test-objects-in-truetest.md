# <a id="concept-9697" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Dynamic test objects in TrueTest


## Understand dynamic test objects

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Dynamic test objects are elements in your application that can change based on user interaction. Dynamic objects do not have a fixed attribute, and they may change each time they appear on the screen, depending on the context or user actions.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">When TrueTest detects dynamic elements, it generates a single, generalized test object that encapsulates these variations. With this, you can add variables to the dynamic object to include properties that are relevant to the AUT. This variable represents the changing aspect of the object.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">For example, consider featured products on an E-commerce website home page. Each link has unique attributes such as <code className="ph codeph">product_name</code> and a distinct <code className="ph codeph">href</code> pointing to different product IDs. Despite these differences, they are fundamentally product links. TrueTest (1) recognizes UI elements of this dynamic nature, (2) generates a <code className="ph codeph">feature_product_link</code> object, which you can (3) add specific variables such as "product ID" to it.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">This approach ensures that your tests remain accurate even when elements change dynamically, and improves your effort in managing test objects.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="sectiondiv"><strong className="ph b">Key features of TrueTest dynamic objects</strong><ul className="ul"><li className="li">Groups together elements with different attributes but the same function.</li><li className="li">Users can define variable attributes specific to the test environment.</li><li className="li">Generates a unified test case for elements that perform the same action, reducing the need for multiple similar test cases.</li></ul></div>

## Work with dynamic test objects in Katalon Studio

<p xmlns="http://www.w3.org/1999/xhtml" className="p">To view dynamic object generated by TrueTest, in the <span className="ph uicontrol">Tests Explorer</span> panel, go to <span className="ph uicontrol">Object Repository</span> &gt; <span className="ph uicontrol">AI-Generated</span> and expand the <span className="ph uicontrol">Dynamic Objects</span> folder.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p"><img className="image" width={400} src={useBaseUrl("/beac1c46-240b-480a-b30f-f145c19157ce/truetest-dynamic-objects-folder.png")} alt="View dynamic objects folder" /></p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">A dynamic test object can be identified using the four supported locator methods: XPath, Attributes, CSS, and Smart Locator. The dynamic properties of the object are configured with variables.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p"><img className="image" width={600} src={useBaseUrl("/457240da-98b7-4291-b9ce-2fc01291098a/truetest-dynamic-object-locator.png")} /></p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">When you use dynamic test objects in a test case, the values for these variables are assigned to specific variables within the test script. TrueTest provides default values for the variables, but you can replace the default values with other environment-specific values.</p>
