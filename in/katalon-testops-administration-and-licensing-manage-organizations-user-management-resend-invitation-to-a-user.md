<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li"><p lang="en" className="p">Make sure you are an Account Admin or possess the relevant permissions. Go to <a className="xref" href="/katalon-testops/administration-and-licensing/manage-systems/permissions/about-roles">roles</a> or <a className="xref" href="/katalon-testops/administration-and-licensing/manage-systems/permissions/about-permissions">permissions</a> for more information or learn how to <a className="xref" href="/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-account-administrators">assign an Account Admin here</a>.</p></li></ul></div>
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">If the invitation link expires and the user hasn't accepted it, you can resend the invitation.</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph menucascade"><span className="ph uicontrol">Admin Settings</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Organization</span></span> and select the <span className="ph uicontrol">User Management</span> tab.
