# <a id="troubleshooting-2106" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Error "HTTP method that is not supported by the mapped resource" when Tap/Swipe on Mobile

<section xmlns="http://www.w3.org/1999/xhtml" className="section condition"><div className="p">You are unable to perform the Swipe action on your device and might encounter the following error:<pre className="pre codeblock"><code>Caused by: org.openqa.selenium.UnsupportedCommandException: The requested resource could not be found, or a request was received using an HTTP method that is not supported by the mapped resource</code></pre></div><p className="p">Refer to the two causes below to identify your solutions.</p></section> 
<div xmlns="http://www.w3.org/1999/xhtml" className="bodydiv troubleSolution"><section className="section cause"><p className="p">You might encounter the error if your XCUITest is version 7.x. Currently, Katalon Studio supports XCUITest version 5.x. You need to remove your current XCUITest, then reinstall it.</p></section><section className="section remedy"><ol className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Uninstall the current XCUITest:</span><div className="itemgroup info"><pre className="pre codeblock"><code>appium driver uninstall xcuitest</code></pre></div></li><li className="li step stepexpand"><span className="ph cmd">Install XCUITest version 5.x. For example:</span><div className="itemgroup info"><pre className="pre codeblock"><code>appium driver install xcuitest@5.0.0</code></pre></div></li></ol></section></div>
<div xmlns="http://www.w3.org/1999/xhtml" className="bodydiv troubleSolution"><section className="section cause"><p className="p">You might encounter the error if your UIAutomator2 Driver is version 3.x.x.</p><p className="p">Katalon Studio has not supported UIAutomator2 Driver version 3.x.x. You need to downgrade to UIAutomator2 <span style={{fontFamily: 'monospace'}} className="ph tt">v2.10.0</span> and remove the UIAutomator2 server in the device.</p></section><section className="section remedy"><ol className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Open a terminal to uninstall the current uiautomator2:</span><div className="itemgroup info"><pre className="pre codeblock"><code>appium driver uninstall uiautomator2</code></pre></div></li><li className="li step stepexpand"><span className="ph cmd">Go to <code className="ph codeph">&lt;&lt;user directory&gt;&gt;/.katalon/tools/android_sdk/platform-tools</code> then open a terminal/cmd there, run the following command:</span><div className="itemgroup info"><pre className="pre codeblock"><code>./adb devices{"\n"}{"\n"}./adb shell pm list package -3</code></pre></div><div className="itemgroup stepresult">You will see a list of the contained items as below:<pre className="pre codeblock"><code>package:io.appium.settings{"\n"}package:io.appium.uiautomator2.server.test{"\n"}package:io.appium.uiautomator2.server{"\n"}package:io.appium.android.apis{"\n"}package:com.example.myapplication</code></pre></div></li><li className="li step stepexpand"><span className="ph cmd">From the same terminal, uninstall the old uiauotmator2 server by running the below command:</span><div className="itemgroup info"><pre className="pre codeblock"><code>./adb uninstall io.appium.uiautomator2.server.test{"\n"}./adb uninstall io.appium.uiautomator2.server</code></pre></div></li><li className="li step stepexpand"><span className="ph cmd">Re-install the new uiautomator2 at your root folder terminal:</span><div className="itemgroup info"><pre className="pre codeblock"><code>appium driver install uiautomator2@2.10.0</code></pre></div></li></ol></section></div>
