# <a id="concept-jn6ka6bd" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Mobile testing using an Android emulator

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">Learn how to perform mobile testing in Katalon Studio using an Android emulator.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">The Android Emulator simulates Android devices on your computer   so that you can test your application on a variety of devices and   Android API levels without needing to have each physical device. To   learn more about the Android emulator capabilities and system   requirements, you can refer to this Android developer document: <a className="xref j-external-link" href="https://developer.android.com/studio/run/emulator" target="_blank">Run apps     on the Android Emulator</a>.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">When performing mobile testing using an Android emulator in Katalon Studio, you can test as if you were using a <a className="xref" href="/katalon-studio/cookbooks/mobile-testing-cookbook/mobile-testing-on-a-real-android-device">real Android device</a> or <a className="xref" href="/katalon-studio/cookbooks/mobile-testing-cookbook/mobile-testing-on-a-real-ios-device">iOS device</a>. However, you need to follow these pre-testing steps:</p> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol"><li className="li"><p className="p"><strong className="ph b">Install Appium</strong> <strong className="ph b">and WebDriver</strong>: You need Appium 2.x to connect Katalon Studio with your emulator. </p></li><li className="li"><p className="p"><strong className="ph b">Install Android Studio</strong>: Android Studio allows developers to build high-quality applications for the Android platform. You will be using this platform to create your emulator.</p></li><li className="li"><p className="p"><strong className="ph b">Create and launch your emulator</strong>: Using Android Studio, create and launch your emulator according to your emulator and use case specifications. </p></li><li className="li"><p className="p"><strong className="ph b">Ensure you have the correct  Android SDK installed</strong>: This is to ensure that you can run your app compatible with the emulator you created in Android Studio. Refer to the following link to secure the Android SDK version for testing: <a className="xref j-external-link" href="https://developer.android.com/about/versions" target="_blank">[Download] Android release versions</a>.</p></li></ol> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p"> </p> 

## <a id="task-7140" class="anchor_top_offset"/>Install Appium 2.x and WebDriver

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">Follow the steps to install Appium 2.x and other dependencies.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context"> </section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Download and install <a className="xref j-external-link" href="https://nodejs.org/en/" target="_blank">Node.js 14+</a>.</span><div className="itemgroup info"><div className="note note note_note"><span className="note__title">Note:</span> <p className="p">Make sure you install Node.js into a location with full Read/Write permission.</p></div></div></li><li className="li step stepexpand"><span className="ph cmd">Download and install <a className="xref j-external-link" href="https://www.npmjs.com/" target="_blank">Node Package Manager 8+ (NPM)</a>. This is usually bundled with Node.js, but you can upgrade independently.</span></li><li className="li step stepexpand"><span className="ph cmd">Download and install the latest version of Appium (2.x and later) using NPM. Copy and paste the command-line argument as follows: </span><div className="itemgroup info"><pre className="pre codeblock"><code>npm install -g appium</code></pre><div className="note note note_note"><span className="note__title">Note:</span> <p className="p">Some emulators support Appium directly when installed. If you want to run an application on an emulator, check your emulator settings before installing Appium.</p></div></div></li><li className="li step stepexpand"><span className="ph cmd">Installing Appium 2.x only installs the Appium server, but not the WebDriver. Install the recommended version of the <a className="xref j-external-link" href="https://github.com/appium/appium-uiautomator2-driver" target="_blank">Appium UiAutomator2 Driver</a> (version 2.45.1). The Appium UiAutomator2 Driver for Android native and web apps (via hybrid mode) is based on the Google UiAutomator framework. </span><div className="itemgroup info"><div className="p">Execute the following command: <pre className="pre codeblock"><code>appium driver install uiautomator2@2.45.1</code></pre></div></div></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">You have installed Appium 2.x server and WebDriver. Scroll down or click on the link to start creating your Android emulator: <a className="xref" href="/katalon-studio/cookbooks/mobile-testing-cookbook/mobile-testing-using-an-android-emulator#id_2-eujadspl">Install Android Studio</a>.</section>

### <a id="id_2-eujadspl" class="anchor_top_offset"/>Install Android Studio

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Download and install Android Studio. You can download Android Studio from the Android developer website here: <a className="xref j-external-link" href="https://developer.android.com/studio" target="_blank">Android Studio</a>. </p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p"> Next, create an Android Studio project for your new emulator.
