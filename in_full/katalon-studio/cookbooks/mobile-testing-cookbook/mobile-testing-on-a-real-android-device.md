### How it works

The Mobile Recorder utility in Katalon Studio helps you record your mobile test cases effectively. Here's how it works:
1. Perform actions on your preferred mobile device, emulator, or simulator, and Mobile Recorder will capture these actions.

2. The recorded actions are converted into automated test scripts, which you can view in the Test Case Editor in Manual view or Script view, which you will learn later on.

3. Mobile Recorder integrates with Katalon Studio's Object Repository, where all UI elements interacted with during the recording are stored. This will be discussed later.

4. Users can playback the recorded test cases to ensure that the scripts work as expected.

5. The utility also supports debugging, enabling users to step through the test execution and identify any issues.

To better understand how Mobile Recorder works, use it to record your first mobile test case. See: [Record a mobile test case](/katalon-studio/cookbooks/mobile-testing-cookbook/mobile-testing-on-a-real-android-device#record-a-mobile-test-case).
