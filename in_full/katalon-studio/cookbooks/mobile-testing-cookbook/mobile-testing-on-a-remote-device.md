# <a id="concept-2629" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Mobile testing on a remote device

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">Learn how to perform mobile testing on a remote device.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Remote devices allow testers to run their mobile applications on a wide range of real devices, emulators, and simulators without physically owning or connecting to each device.   Remote devices for mobile testing are useful for cross-platform compatibility.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">In Katalon Studio, you can configure and use remote devices for mobile app testing by setting up the desired capabilities for the remote device, such as the device type, platform version, and other specific configurations. This allows you to test your mobile applications on a variety of devices without the need to have them physically available. </p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">To begin, you need to <a className="xref" href="/katalon-studio/cookbooks/mobile-testing-cookbook/the-mobile-testing-cookbook#task-352">create a new test project</a>. Afterwards, you need to set up your mobile testing environment for remote devices. See: <a className="xref" href="#concept-v9d3lh9r">Set up your mobile testing environment</a>.</p>

## <a id="concept-u2om5ew7" class="anchor_top_offset"/>Edit mobile test case

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">Editing a mobile test case can be done using a manual editor or via script view, and utilizing supported keywords.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Editing test cases in Katalon Studio can be done via manual view or script view as we have demonstrated previously. Simply access the Test Case Editor and follow the steps:</p> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol"><li className="li"><p className="p">In the <span className="ph uicontrol">Manual</span> tab, use the menu items or edit inline to add or edit your keywords. <img className="image" src={useBaseUrl("https://tw-cdn.katalon.com/katalon-studio/Test_Case_Editor_manual_view.png")} alt="Edit test case in Test Case Editor manual view (Manual tab)." /></p></li><li className="li"><p className="p">In the <span className="ph uicontrol">Script</span> tab, you can use the Content Assist function to edit the test case, of which has been converted into Groovy script.
