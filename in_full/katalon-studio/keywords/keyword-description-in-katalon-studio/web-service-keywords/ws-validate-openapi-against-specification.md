# <a id="concept-1843" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>[WS] Validate OpenAPI against Specification


## Description

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Validate an OpenAPI/Swagger response body, request body, or string against an OpenAPI/Swagger specification. The OpenAPI/Swagger specification input can be a string, URL, or file path.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Keyword name: <code className="ph codeph">validateOpenAPIAgainstSpecification</code></p>
