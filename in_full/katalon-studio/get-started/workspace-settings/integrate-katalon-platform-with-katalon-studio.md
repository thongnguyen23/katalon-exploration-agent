# <a id="concept-8947" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Integrate Katalon Platform with Katalon Studio

<div xmlns="http://www.w3.org/1999/xhtml" className="p"><span className="ph">Katalon TestOps</span> and <span className="ph">Katalon TestCloud</span> integration in <span className="ph">Katalon Studio</span> allows you to:<ul className="ul"><li className="li"><p className="p">Upload test results to <span className="ph">Katalon TestOps</span> for test management and reports. See: <a className="xref" href="/katalon-studio/test-reports/upload-test-results-from-katalon-studio-to-katalon-testops-manually">Upload Katalon Studio test results to TestOps</a></p></li><li className="li"><p className="p">Execute tests on cloud-based environments with <span className="ph">Katalon TestCloud</span>. Learn more: <a className="xref" href="/katalon-testcloud/testcloud-overview">TestCloud overview</a>.</p></li></ul></div>
<p xmlns="http://www.w3.org/1999/xhtml" className="p">This document shows you how to integrate <span className="ph">Katalon TestOps</span> and <span className="ph">Katalon TestCloud</span> with <span className="ph">Katalon Studio</span>.</p> 

## <a id="task-151" class="anchor_top_offset"/>Enable TestOps and TestCloud integration

<section xmlns="http://www.w3.org/1999/xhtml" className="section context">To integrate <span className="ph">Katalon TestOps</span> and <span className="ph">Katalon TestCloud</span> with <span className="ph">Katalon Studio</span>, follow these steps:</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Open your project in <span className="ph">Katalon Studio</span>.</span></li><li className="li step stepexpand"><span className="ph cmd">In the main toolbar, click on the Katalon Platform button.</span><div className="itemgroup info"><img className="image" width={400} src={useBaseUrl("/12b1f8f8-d014-45ae-aa99-8d6dccaf443f/KS_Katalon_Platform_integration_button.png")} alt="Katalon Platform button in Katalon Studio main toolbar" /><p className="p">Alternatively, you can go to <span className="ph uicontrol">Project</span> &gt; <span className="ph uicontrol">Settings</span> &gt; <span className="ph uicontrol">Katalon Platform</span>.</p><p className="p"><img className="image" width={700} src={useBaseUrl("/26507fa3-dd3d-44cf-a2fa-3d77ad1635da/ks970-settings-platform.png")} /></p></div></li><li className="li step stepexpand"><span className="ph cmd">Tick on the <span className="ph uicontrol">Enable Katalon Platform Integration</span> checkbox.</span><div className="itemgroup info">This option automatically enables <span className="ph">Katalon TestCloud</span> integration and uploads all test reports to <span className="ph">Katalon TestOps</span>. You can deselect any of the options based on your preference.<div className="p">Once the connection is successful, <span className="ph">Katalon Studio</span> fetches all Projects from the Organization you belong to.<div className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li"><p className="p">The settings apply for <span className="ph">TestOps</span> and <span className="ph">TestCloud</span>. If you want to execute tests with <span className="ph">TestCloud</span> and upload test reports to <span className="ph">TestOps</span>, you need to choose the Organization that has an active <span className="ph">TestCloud</span> subscription or trial. See <a className="xref" href="/katalon-platform/administer/administration-tasks/payment-and-subscription/purchase-katalon-subscription#task-q39m18ta">Purchase Katalon product via <span className="ph">TestOps</span>  website</a>.</p></li></ul></div></div></div></li><li className="li step stepexpand"><span className="ph cmd">Choose your <span className="ph uicontrol">Project</span> from the dropdown menu.</span><div className="itemgroup info">If you are the Owner or Admin, you can also click <span className="ph uicontrol">New Project</span> to create a new project. </div></li><li className="li step stepexpand"><span className="ph cmd">Click <span className="ph uicontrol">Apply &amp; Close</span>.</span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">You can execute tests in a cloud-based environment. Your test results are automatically uploaded to <span className="ph">Katalon TestOps</span> every time you run test suites in <span className="ph">Katalon Studio</span>.</section> 

## <a id="id_4" class="anchor_top_offset"/>Override authentication

<p xmlns="http://www.w3.org/1999/xhtml" className="p">You might need to override authentication when you want to integrate <span className="ph">Katalon Studio</span> with <span className="ph">Katalon TestOps</span> using a TestOps private instance. To learn more about TestOps private instance offering and how to enable your private instance from <span className="ph">Katalon Studio</span>, see: <a className="xref" href="#">TestOps Private Instance integration</a>​.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="p"><div className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li"><p className="p">You can override authentication with <span className="ph uicontrol">TestCloud</span> in <span className="ph">Katalon Studio</span>.</p></li></ul></div></div>
<p xmlns="http://www.w3.org/1999/xhtml" className="p">In <span className="ph uicontrol">Katalon Studio</span> &gt; <span className="ph uicontrol">Project</span> &gt; <span className="ph uicontrol">Settings</span> &gt; <span className="ph uicontrol">Katalon Platform</span>, there is an option to override authentication.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p"><img className="image" width={700} src={useBaseUrl("/52ad0aa4-74af-42d1-b28d-7161a563912e/ks970-override-authentication.png")} /></p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">By default, the <span className="ph uicontrol">Override authentication</span> option is disabled, which means the <span className="ph uicontrol">Server URL</span> and user credentials to connect with <span className="ph">Katalon TestOps</span> are inherited from what has been filled in the <span className="ph uicontrol">Activation</span> dialog.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">With the <span className="ph uicontrol">Override authentication</span> option enabled, you can input a different <span className="ph uicontrol">Server URL</span> and user credentials. This information is saved in <code className="ph codeph">&lt;project folder&gt;/settings/internal/com.kms.katalon.integration.analytics.properties</code>.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="p"><div className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li"><p className="p">Use <code className="ph codeph">https://testops.katalon.io</code> as the Server URL for integration with Katalon TestOps and Test Cloud. This URL acts as the gateway and ensures correct routing to necessary services.</p></li><li className="li"><p className="p">If you experience issues with the <span className="ph uicontrol">Override authentication</span> option being disabled, check if your account is part of an organization that uses SAML for authentication. See version 9.3.0 release notes: <a className="xref j-external-link" href="https://docs.katalon.com/katalon-studio/release-notes/katalon-studio-release-notes-version-9.x#known-limitations-5" target="_blank">Known limitations</a>.</p></li></ul></div></div>
