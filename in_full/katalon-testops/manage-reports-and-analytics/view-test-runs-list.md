This document shows you what the View Test Runs List section is and how to use it.

## Prerequisites
- You must possess the Test Lead or Tester role to perform this actions. Go to [Roles](/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-account-administrators) or [Permissions](/katalon-testops/administration-and-licensing/manage-systems/permissions/about-permissions) for more information or learn how to [assign a Project Admin here](/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-project-administrators)

---


View all your test runs or apply filters to find the one you need easily from **Reports > Test Runs**. This provides comprehensive overviews of finished test executions with calculated statistics and results, allowing for easy analysis and reporting. 

## Steps

1. Go to **Reports** > **Test Runs**. The Test Runs list displays all your test runs in a list, including completed and running executions with details such as test suite, time of execution, duration, type, test result, and executor.

<br/>

<img src="https://tw-cdn.katalon.com/katalon-testops/Reports/Test Runs/Reports Test Runs Base.png" alt="The Test Run list in Katalon TestOps." width="1080"/> 

<br/>

2. Enter search parameters to filter for specific test runs. You can:
- **Search**: Allows you to match text to the name of your test run.
- **Input dates**: Allows you to limit the time frame based on when the test run was executed.
- **Select status**: Allows you to filter for test runs based on their execution status.
- **Select executor**: Allows you to filter test runs based on the user who executed it.
- **Select type**: Allows you to filter for manual or automated test cases.
