title: Edit a user's Organization
---

Learn how to change the Organization a user is affiliated with.

## Prerequisites

- Make sure you are an Account Admin or possess the relevant permissions. Go to [roles](/katalon-testops/administration-and-licensing/manage-systems/permissions/about-roles) or [permissions](/katalon-testops/administration-and-licensing/manage-systems/permissions/about-permissions) for more information or learn how to [assign an Account Admin here](/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-account-administrators).

---

Change a user's Organization via their user detail page.

## Edit a user's organization

1. [Navigate to your chosen user's User Detail page](/katalon-testops/administration-and-licensing/manage-organizations/user-management/view-the-user-detail-page).

2. Click on the **Change** button under the label **Organization**. This can be found within the information box at the top of the page.

3. The **Change Organization** dialog box appears. Select the new Organization from the dropdown menu.

4. Click **Save**.

## Result

A toast notification confirms you've changed the user's Organization successfully.
