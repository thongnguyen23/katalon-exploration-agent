---
title: Create an Azure DevOps integration
---
This document shows you how to create an integration for Azure DevOps within Katalon TestOps. 

:::info Important
- You must possess the Account Admin or System Admin role to perform this action. Go to [Roles](/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-account-administrators) or [Permissions](/katalon-testops/administration-and-licensing/manage-systems/permissions/about-permissions) for more information or learn how to [assign an Account Admin here.](/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-account-administrators)
:::

Create an integration with Azure DevOps to improve test automation efficiency, centralize test management, and strengthen DevOps workflows.

1. Go to **Admin > System > System Integrations**. The Integration list appears.
2. Click **+ Create Integration**.

<br/>

<img src="https://tw-cdn.katalon.com/katalon-testops/Administration and Licensing/Manage Systems/System Integrations/Azure DevOps/System Integrations Page Create Integration.png" alt="The System Integrations page in Katalon TestOps with Create Integration highlighted." width="1080"/>

<br/>

3. Select **Azure DevOps** from within the ALM and Test management section. This brings you to the Azure DevOps Integration Setup page.

<br/>

<img src="https://tw-cdn.katalon.com/katalon-testops/Administration and Licensing/Manage Systems/System Integrations/Azure DevOps/Azure DevOps Integration.png" alt="The Azure DevOps integration in Katalon TestOps." width="1080"/>

<br/>

4. Input your credentials.
5. Click the **Test Connection** to check your credentials. If successful, you'll see a confirmation message.

<br/>

<img src="https://tw-cdn.katalon.com/katalon-testops/Administration and Licensing/Manage Systems/System Integrations/Azure DevOps/Update Azure DevOps Integration Setup Connect Successfully.png" alt="The Azure DevOps integration connecting successfully in Katalon TestOps." width="1080"/>

<br/>

6. Click **Save**. A notification confirms you have successfully created the integration successfully. You are brought back to the Integration list where your new integration appears.
