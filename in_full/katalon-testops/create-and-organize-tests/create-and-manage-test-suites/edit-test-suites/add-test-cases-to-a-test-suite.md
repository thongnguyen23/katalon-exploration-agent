# <a id="task-299" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Add test cases to a test suite

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This document shows you how to add test cases to an existing test suite. </p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Add test cases by going to a test suite's details and clicking on <span className="ph uicontrol">Add (+)</span> from within the Add Test Case section. </section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph menucascade"><span className="ph uicontrol">Tests</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Test Suites</span></span>.</span></li><li className="li step stepexpand"><span className="ph cmd">Click on the name of the test suite you would like to add test cases to. The test suite's details page appears.     </span></li><li className="li step stepexpand"><span className="ph cmd">Click on <span className="ph uicontrol">Add Test Case</span>. </span></li><li className="li step stepexpand"><span className="ph cmd">Optionally, enter search filters to make it easier to find the test cases you want to add. </span><div className="itemgroup info"><ul className="ul"><li className="li"><strong className="ph b">Search</strong>: allows you to match text to the name of your test case.</li><li className="li"><strong className="ph b">Repository</strong>: allows you to specify from which repository you would like ot fetch your test cases from.</li><li className="li"><strong className="ph b">Type</strong>: allows you to filter test cases to only show the ones with your selected tag.</li><li className="li"><strong className="ph b">Status</strong>: allows you to filter test cases based on the working status you've ticked.</li><li className="li"><strong className="ph b">Author</strong>: Allows you to select test cases that have been authored by a specific individual.</li></ul></div></li><li className="li step stepexpand"><span className="ph cmd">Upon identifying the test cases you'll add to the test suite, click on the <span className="ph uicontrol">Add (+)</span> button that's at the rightmost column of every test case row. </span></li><li className="li step stepexpand"><span className="ph cmd">Verify that your test cases have been added by going back to the Test Case List section and checking manually. </span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">You have added additional test cases to your test suite. </section>
