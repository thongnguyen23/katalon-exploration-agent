# <a id="task-7777" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Remove test cases from a test suite

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc"> </p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Remove test cases by going to a test suite's details and clicking on <span className="ph uicontrol">Subtract (-)</span> from within the Test Case List section. </section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step"><span className="ph cmd">Go to <span className="ph menucascade"><span className="ph uicontrol">Tests</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Test Suites</span></span>.</span></li><li className="li step"><span className="ph cmd">Click on the name of the test suite you would like to subtract test cases from. The test suite's details page appears.</span></li><li className="li step"><span className="ph cmd">Click on the <span className="ph uicontrol">Subtract (-)</span> button that's at the rightmost column of every test case row. </span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">A toast notification confirms that you've removed the test cases from the test suite. The subtracted test cases also disappear from the Test Case List. </section>
