<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This section shows you how to move test cases.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Click on a test case's three-dot menu from the <span className="ph uicontrol">Test Directory</span> and select <span className="ph uicontrol">Move</span>.</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph uicontrol">Tests</span> &gt; <span className="ph uicontrol">Test Cases</span>.</span></li><li className="li step stepexpand"><span className="ph cmd">Click on the three-dot menu of the test case you would like to move at the rightmost column and shows upon hovering.</span><ul className="ul choices"><li className="li choice">Alternatively, you could click on the check box then click on <span className="ph uicontrol">Move to</span> in the toolbar that appears. You can select more than one test case using this method.</li></ul><div className="itemgroup info"><img className="image" width={700} src={useBaseUrl("/0d725281-2469-4323-9de9-34a47177f77b/gen3-move-test-case.png")} /></div></li><li className="li step stepexpand"><span className="ph cmd">Click the <span className="ph uicontrol">Move to</span> icon.</span><div className="itemgroup stepresult">A dialog box appears. <section xmlns="http://www.w3.org/1999/xhtml" className="section result">A toast notification confirms that you've moved your test case.</section>
