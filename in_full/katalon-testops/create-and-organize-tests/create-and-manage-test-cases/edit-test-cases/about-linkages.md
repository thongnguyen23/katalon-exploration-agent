# <a id="task-1384" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>About linkages

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This document shows you how to view or edit the linkages between your test cases. This allows you to easily identify the relationships between your test cases and other attributes such as requirements or defects.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">View or edit linkages by going to a test case's details.</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph uicontrol">Tests</span> &gt; <span className="ph uicontrol">Test Cases</span> in the sidebar. The <span className="ph uicontrol">Test Directory</span> page appears.</span></li><li className="li step stepexpand"><span className="ph cmd">Click on the name of the test case linkage you'd like to view. The test case's details page appears.</span></li><li className="li step stepexpand"><span className="ph cmd">Click on <span className="ph uicontrol">Linkages</span>. A mind map shows your test case's relationships with other test cases, as well as related requirements and defects. </span><div className="itemgroup info"><div className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li"><p className="p">You can link or unlink linkages at any time by clicking on the link icon in each linkage's box.</p></li></ul></div></div><div className="itemgroup info"><img className="image" src={useBaseUrl("/38ba27c0-7acb-40e3-a64f-d80810026168/TO3GA1_Linkage_Sample.png")} /></div></li></ol> 
<div xmlns="http://www.w3.org/1999/xhtml" className="li stepsection">Edit a <a className="xref" href="/katalon-testops/plan-and-collaborate/view-requirement-details">requirement</a> linkage</div>
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps" start={4}><li className="li step stepexpand"><span className="ph cmd">Unlink the linkage you would like to edit by clicking on the icon of a broken link. </span></li><li className="li step stepexpand"><span className="ph cmd">Click on <span className="ph uicontrol">+ Click to link requirements</span>.
