# <a id="task-9689" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>View test cases

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This document shows you how to view ta complete list of your test cases.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">View your test cases by navigating to the <span className="ph uicontrol">Test Directory</span>.</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph uicontrol">Tests</span> &gt; <span className="ph uicontrol">Test Cases</span> in the sidebar. The <span className="ph uicontrol">Test Directory</span> page appears.</span></li><li className="li step stepexpand"><span className="ph cmd">Select your preferred view for accessing your test cases. Pick one of the following:</span><div className="itemgroup info"><div className="p">From the top section of the sidebar, you can click: <ul className="ul"><li className="li"><span className="ph uicontrol">My Tests</span> to display the test cases you have authored, or the test cases you've been assigned or have contributed to.</li><li className="li"><span className="ph uicontrol">Recent</span> to display all your test cases organized according to tags: <span className="ph uicontrol">Manual</span> or <span className="ph uicontrol">Automated</span>. </li><li className="li"><span className="ph uicontrol">New</span> to display all test cases created by you in the last 7 days.</li></ul></div><div className="p">From the bottom section of the sidebar, you can click:<ul className="ul"><li className="li"><span className="ph uicontrol">Repositories</span> to display all your test cases from Git repositories and Katalon Cloud organized in folders.</li><li className="li"><span className="ph uicontrol">Tags</span> to display all your test cases organized according to their tags. Two are available: manual and automated.</li></ul></div></div></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result"><p className="p">Selecting a view results in all of your test cases showing as a list within the <span className="ph uicontrol">Test Directory</span>'s main window.</p><p className="p">To learn more about an individual test case and its attributes, <a className="xref" href="/katalon-testops/create-and-organize-tests/create-and-manage-test-cases/view-test-case-details">view a test case's details</a>.</p></section>
