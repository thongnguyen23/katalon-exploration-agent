# <a id="concept-1916" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Local testing with TestCloud in TestOps

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This document shows you how to set up TestCloud Tunnel in <span className="ph">TestOps</span> and perform local testing.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">If your application under test is locally hosted in a private network, you can set up a tunnel for <span className="ph">TestCloud</span> server to access the application. See: <a className="xref" href="/katalon-testcloud/local-testing-with-testcloud">Local testing with TestCloud</a>.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="p">To perform local testing with <span className="ph">TestCloud</span> (on TestOps), you need to:<ol className="ol"><li className="li"><p className="p">Download and configure the TestCloud Tunnel.</p></li><li className="li"><p className="p">Run tests with the <span className="ph uicontrol">Private/Local Testing</span> option enabled.</p></li></ol></div>

## <a id="task-4052" class="anchor_top_offset"/>Configure TestCloud Tunnel

<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li">For detailed information on TestCloud Tunnel and how to use it, see <a className="xref" href="/katalon-testcloud/local-testing-with-testcloud">TestCloud Tunnel</a>.</li><li className="li">Whitelist the TestCloud Tunnel hostnames in your private network. See: <a className="xref" href="/katalon-testcloud/network-configuration-for-testcloud">Network configuration for TestCloud</a>.</li></ul></div>
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">You need to download and activate the TestCloud Tunnel to start test executions for the local application.<div className="note important note_important"><span className="note__title">Important:</span> <ul className="ul"><li className="li">To allow User Datagram Protocol (UDP) connections, the proxy must be configured.</li><li className="li">If you use a Man-in-the-Middle (MITM) proxy, it must be configured to allow Transport Layer Security (TLS) connections.</li></ul></div></section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph uicontrol">Configurations</span> &gt; <span step stepexpand"><span className="ph cmd">Switch to the <span className="ph uicontrol">Setup</span> tab.</span><div className="itemgroup info">You will see an on-screen step-by-step instruction on how the <span className="ph uicontrol">Test Run List</span> page and click on the <em className="ph i">Play</em> icon to run your tests.</span></li></ol>

## <a id="task-9430" class="anchor_top_offset"/>Run tests with TestCloud Tunnel

<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Follow these steps to run local testing with TestCloud Tunnel.</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Sign in to <a className="xref j-external-link" href="https://testops.katalon.io/login" target="_blank">Katalon TestOps</a> and go to your Project.</span></li><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph uicontrol">Test Execution</span> &gt; <span className="ph uicontrol">Schedule Test Run</span>.</span><div className="itemgroup stepresult">The <span className="ph uicontrol">Schedule Test Run</span> dialog appears.</div></li><li className="li step stepexpand"><span className="ph cmd">In the <span className="ph uicontrol">Environment</span> section, click on the drop-down menu and select <span className="ph uicontrol">More options</span>.</span><div className="itemgroup stepresult">The dialog displays as below.<p className="p"><img className="image" width={850} src={useBaseUrl("/6f750340-4633-11ee-9fb5-0242c7a41fd4/TC_local_testing_option_enabled.png")} /></p></div></li><li className="li step stepexpand"><span className="ph cmd">Switch the <span className="ph uicontrol">Private/Local Testing</span> toggle on.</span><div className="itemgroup info"><p className="p">You can choose a specific tunnel to execute the test or use <span className="ph uicontrol">Auto-selected tunnel</span>. With the auto-select option, TestCloud will use the most available tunnel, prioritizing private tunnels over shared tunnels.</p><p className="p"> In case your tests also perform API calls, check the <span className="ph uicontrol">Also Include API Calls</span> option.</p><div className="note note note_note"><span className="note__title">Note:</span> <p className="p">This toggle is also applied when you whitelist <span className="ph">TestCloud</span> IPs instead of using Tunnel. See: <a className="xref" href="/katalon-testcloud/network-configuration-for-testcloud">Network configuration for TestCloud</a>.</p></div></div></li><li className="li step stepexpand"><span className="ph cmd">Select the testing environment in the <span className="ph uicontrol">TestCloud</span> section.</span></li><li className="li step stepexpand"><span className="ph cmd">Return to the <span className="ph uicontrol">Schedule Test Run</span> dialog, then click <span className="ph uicontrol">Schedule / Run</span>.</span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">You have successfully run tests with TestCloud Tunnel enabled.</section>
