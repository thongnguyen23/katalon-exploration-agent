# <a id="concept-7045" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Local testing with TestCloud in Katalon Studio

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This document shows you how to set up TestCloud Tunnel in <span className="ph">Katalon Studio</span> and perform local testing.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">If your application under test is locally hosted in a private network, you need to set up a tunnel for <span className="ph">TestCloud</span> server to access the application. See: <a className="xref" href="/katalon-testcloud/local-testing-with-testcloud">Local testing with TestCloud</a>.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">In <span className="ph">Katalon Studio</span>, you can use the <span className="ph uicontrol">Tunnel Setup Helper</span> to download and configure <span className="ph">TestCloud</span> Tunnel.</p> 

## <a id="task-3854" class="anchor_top_offset"/>Configure TestCloud Tunnel

<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li"><span className="ph">TestCloud</span> integration is enabled in <span className="ph">Katalon Studio Enterprise (KSE)</span>, see: <a className="xref" href="/katalon-testcloud/integrations/enable-testcloud-integration-in-katalon-studio">Enable  TestCloud integration in Katalon Studio</a>.</li><li className="li">TestCloud Tunnel Server hostnames are whitelisted. See: <a className="xref" href="/katalon-testcloud/network-configuration-for-testcloud#concept-9502__section-2427-network-issues-and-solutions-for-testcloud-tunnel">Common network issues and solutions</a>.</li></ul></div>
<section xmlns="http://www.w3.org/1999/xhtml" className="section context"><div className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li">To allow User Datagram Protocol (UDP) connections, the proxy must be configured.</li><li className="li">If you use a Man-in-the-Middle (MITM) proxy, it must be configured to allow Transport Layer Security (TLS) connections.</li></ul></div><p className="p">Follow these steps to set up <span className="ph">TestCloud</span> Tunnel with <span className="ph uicontrol">Tunnel Setup Helper</span>. </p></section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">In <span className="ph">Katalon Studio</span>, click on the dropdown icon of the <em className="ph i">Run</em> button and choose to run with TestCloud.</span></li><li className="li step stepexpand"><span className="ph cmd">In the <span className="ph uicontrol">TestCloud Configuration</span> dialog, select your testing environment, then enable the <span className="ph uicontrol">Private/Local Testing</span> option.</span><div className="itemgroup info">You'll see a  message, as follows:<img className="image" width={500} src={useBaseUrl("/9425e68f-990d-43c8-9c65-1ff43dfbdda4/TestCloud_KS_tunnel_enabled.png")} alt="Katalon Studio - TestCloud Configuration dialog, TestCloud Tunnel not available status" /></div></li><li className="li step stepexpand"><span className="ph cmd">Click the <span className="ph uicontrol">Tunnel Setup Helper</span> link.</span><div className="itemgroup info"><p className="p">The <span className="ph uicontrol">Tunnel Setup Helper</span> dialog appears.<img className="image" width={350} src={useBaseUrl("/8584188c-43bb-4811-9650-6d21fa4cd682/TestCloud_KS_tunnel_setup_helper.png")} alt="Katalon Studio - Tunnel Setup Helper dialog" /></p></div></li><li className="li step stepexpand"><span className="ph cmd">Follow the step-by-step instructions in the dialog to set up the tunnel client in your local machine:</span><ol type="a" className="ol substeps"><li className="li substep substepexpand"><span className="ph cmd">Select your OS and download the .zip file, then unzip it.</span></li><li className="li substep substepexpand"><span className="ph cmd">Open the command-line interface (CLI) and navigate to the directory containing the tunnel executable file. Copy the command line from the dialog, then run it in the CLI.</span><div className="itemgroup info">An example command looks like this:<pre className="pre codeblock"><code>/Applications/kt config --tenant KatalonStudio --username "myusername@katalon.com" --organization-id "myid" --api-key "myapikey"</code></pre><p className="p">You can choose to share the tunnel with other members in the same Organization.</p></div></li><li className="li substep substepexpand"><span className="ph cmd">Use the <code className="ph codeph">kt start</code> command to start the tunnel.</span><div className="itemgroup info"><img className="image" width={500} src={useBaseUrl("/601b8fb3-b710-4edc-a4ad-cc3ddae4213f/testcloud_tunnel_terminal.png")} alt="Sample terminal message for running TestCloud Tunnel" /><div className="note note note_note"><span className="note__title">Note:</span> <p className="p">Keep your CLI open until you have finished running tests.</p></div></div></li></ol></li><li className="li step stepexpand"><span className="ph cmd">Switch back to <span className="ph uicontrol">Tunnel Setup Helper</span> and click <span className="ph uicontrol">Close</span>. </span><div className="itemgroup info">Click <span className="ph uicontrol">Refresh</span> and you should see the message: "<em className="ph i">Tunnel is available</em>".<img className="image" width={500} src={useBaseUrl("/afb554b1-09e9-414a-a7ba-1aa96d2569ea/testcloud_tunnel_available_status.png")} alt="Katalon Studio - TestCloud Configuration dialog - TestCloud Tunnel available" /></div></li><li className="li step stepexpand"><span className="ph cmd">Click <span className="ph uicontrol">Run</span> to start executing your test suite / test suite collection with TestCloud Tunnel.</span></li></ol>
