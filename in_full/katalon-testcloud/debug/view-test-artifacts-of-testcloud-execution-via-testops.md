#### Application performance analytics (Profile)

TestCloud provides the `profiling` capability for tracking performance metrics, such as CPU usage, Memory consumption, network activity, etc., of a mobile app under test. TestCloud will output a raw data file that you can analyze directly or visualize using their preferred tools to gain detailed insights.

In Katalon Studio, go to **Project Settings** > **Desired Capabilities** > **TestCloud** to add the Boolean type `profiling:true` property in `katalon:options`.

<img src="https://tw-cdn.katalon.com/katalon-testcloud/testcloud-debug/testcloud-desired-cap-for-app-performance-tracking.png" alt="Add desired capability to track app performance" width="800" />
<br/>

Go to TestOps to schedule and run your tests. After the test execution is finished, you can find the data file in the **Files** tab.
