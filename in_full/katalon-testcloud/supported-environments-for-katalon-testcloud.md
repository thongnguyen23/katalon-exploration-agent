---
title: Supported environments for Katalon TestCloud
---

This guide provides a list of environments supported by Katalon TestCloud.

:::note
For integration with Katalon Studio, see also: [Supported environments for Katalon Studio and Katalon Runtime Engine](/katalon-studio/supported-environments-for-katalon-studio-and-katalon-runtime-engine-kre).
:::


## Supported operating systems (OS)

You can access TestCloud from both Katalon Studio and TestOps. TestCloud supports the following OS:
- Windows: Web testing
- Linux: Web testing
- macOS: Web testing
- Android: Mobile browser and native application testing
- iOS: Mobile browser and native application testing

## Supported browsers

TestCloud supports the latest versions of most common browsers. The table below shows the latest browser versions that TestCloud supports.

| Desktop Browsers | Latest version on Windows | Latest version on Linux | Latest version on macOS |
| --- | --- | --- | --- |
| Firefox | 139 beta | 138 | 139 beta |
| Chrome | 138 dev | 137 | 138 dev |
| Edge Chromium | 138 dev | N/A | 138 dev |
| Internet Explorer (IE mode in Microsoft Edge) | 11 | N/A | N/A |
| Safari | N/A | N/A | 10-19 |

## Supported mobile browsers

TestCloud supports WebUI testing on browsers of mobile devices. The mobile test environments include built-in browser of each operating system: Chrome for Android and Safari for iOS.

You can select any device from the supported devices list: [Supported mobile devices](/katalon-testcloud/supported-environments-for-katalon-testcloud#supported-mobile-devices).
