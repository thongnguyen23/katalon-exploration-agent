# <a id="concept-4559" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Mobile native app testing with <span xmlns="http://www.w3.org/1999/xhtml" className="ph">TestCloud</span> 

<p xmlns="http://www.w3.org/1999/xhtml" className="p"><span className="ph">TestCloud</span> allows you to perform automated tests on mobile native applications. You can upload a mobile application and tests developed locally in <span className="ph">Katalon Studio</span> to <span className="ph">TestOps</span>, and then use <span className="ph">TestCloud</span> to orchestrate test executions without having to set up local emulators or simulators.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">This guide shows you how to perform mobile native application testing on <span className="ph">TestCloud</span>.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="note important note_important"><span className="note__title">Important:</span> <ul className="ul"><li className="li">An active Katalon TestCloud subscription or trial. See <a className="xref j-external-link" href="https://docs.katalon.com/katalon-platform/administer/katalon-platform-packages/testcloud-feature-comparison#id_2" target="_blank">TestCloud Trial</a>.</li></ul></div>

<div xmlns="http://www.w3.org/1999/xhtml" className="li stepsection">For Test Suite</div>
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Open a test suite.</span></li><li className="li step stepexpand"><span className="ph cmd">In the main toolbar, click the dropdown arrow of the <em className="ph i">Run</em> button and select TestCloud.</span><div className="itemgroup info"><img className="image" width={200} src={useBaseUrl("/2af21b60-c18e-11ed-a4d3-0242cfbc79b5/KS_select_execution_env.png")} /></div><div className="itemgroup stepresult">The <span className="ph uicontrol">TestCloud Configuration</span> dialog appears as below. ## <a id="task-6324" class="anchor_top_offset"/>Run mobile native app tests on TestOps

<section xmlns="http://www.w3.org/1999/xhtml" className="section context"><p className="p">With the mobile application uploaded and the associated mobile test project configured in <span className="ph">TestOps</span>, you can run automated tests on the application with <span className="ph">TestCloud</span>.</p></section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Sign in to <a className="xref j-external-link" href="https://testops.katalon.io/" target="_blank">Katalon TestOps</a> and go to your Project.</span></li>
<li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph uicontrol">Test Execution</span> &gt; <span className="ph uicontrol">Schedule Test Run</span>.</span><div className="itemgroup stepresult">The <span className="ph uicontrol">Schedule Test Run</span> dialog pops up.</div></li>
<li className="li step stepexpand"><span className="ph cmd">In the <span className="ph uicontrol">Environment</span> section, click the drop-down menu and select <span className="ph uicontrol">More options</span>.</span><div className="itemgroup info"><img className="image" width={700} src={useBaseUrl("/0d3821f0-2c37-11ee-bd4d-0242c7a41fd4/TC_environment_select_more_options_button.png")} /></div></li>
<li className="li step stepexpand"><span className="ph cmd">In the <span className="ph uicontrol">Mobile Native App</span> tab, select your mobile device and app.</span><div className="itemgroup info"><img src="https://tw-cdn.katalon.com/katalon-testcloud/mobile-native-app-testing-with-testcloud/tc-mobile-native-app-environment.png" alt="Mobile native app environment" width="800" /></div></li>
<li className="li step stepexpand"><span className="ph cmd">Click <span className="ph uicontrol">Save</span> to return to the <span className="ph uicontrol">Schedule Test Run</span> dialog. </span></li>
<li className="li step stepexpand"><span className="ph cmd">Fill in the required fields and click <span className="ph uicontrol">Run</span> to trigger the test run.</span><div className="itemgroup info"><img className="image" width={600} src={useBaseUrl("/74e70126-3e8b-46bc-b9b5-4231663ade0d/tc-run-mobile-app-test.png")} /></div></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result"><p className="p">To check the progress of your test runs, see <a className="xref" href="/katalon-platform/analyze/reports/view-test-reports/view-test-run-results/view-a-test-run-summary">View session logs</a>.</p></section> 

## <a id="concept-81qkun77" class="anchor_top_offset"/>Run mobile native app tests in Katalon Runtime Engine

<div xmlns="http://www.w3.org/1999/xhtml" className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li">When running tests from KRE to TestCloud environments, you only need a TestCloud subscription; a KRE license is not required.</li></ul></div>
<p xmlns="http://www.w3.org/1999/xhtml" className="p">To run native mobile app tests with <span className="ph">Katalon Runtime Engine (KRE)</span>, we recommend using Command Builder in <span className="ph">Katalon Studio</span> to generate the commands. For detailed instruction, see: <a className="xref" href="/katalon-studio/execute-tests/katalon-runtime-engine/get-started-with-katalon-runtime-engine#id_10">Command Builder in Katalon Studio</a>.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">You can simply specify the mobile environment in the <span className="ph uicontrol">Run Configuration</span> section. Then click <span className="ph uicontrol">Generate Command</span> at the bottom of the dialog to copy the command.</p>
