# <a id="concept-ubasfr09" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Use Mobile Object Spy on TestCloud devices

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">TestCloud provides a wide range of mobile devices, supporting both Android and iOS, that are accessible from Katalon Studio. You just need to upload your application file to TestOps and directly capture the application objects.</p> 

## Requirements

<ul xmlns="http://www.w3.org/1999/xhtml" className="ul"><li className="li"><span className="ph">Katalon Studio Enterprise (KSE)</span> version 9.5.0 onwards.</li><li className="li">A  <span className="ph">TestCloud</span>     Mobile Native App Testing subscription.</li></ul>
