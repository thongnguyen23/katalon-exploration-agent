# <a id="concept-5371" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Types of variables in TrueTest

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">TrueTest generated variables  require user input before executing test cases. This guide will help you understand the different types of variables generated by TrueTest and the actions you need to take to ensure your tests run smoothly.</p> 

## Global Variables

<p xmlns="http://www.w3.org/1999/xhtml" className="p">TrueTest stores global variables  in the global profile of Katalon Studio.  These variables are not provided with sample values, so you will need to input the correct values before executing the test cases. After defining the values, you can use them across all test artifacts in a project.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="p">TrueTest generates global variables from the following sources:<dl className="dl"><dt className="dt dlterm">URL Query parameters</dt><dd className="dd">TrueTest does not record the query parameters' values, therefore  cannot automatically suggest the appropriate sample data. Instead, TrueTest divides the URL into two parts:  <code className="ph codeph">application_domain</code>  and <code className="ph codeph">query_params</code>. For example, if the URL is <code className="ph codeph">abc.com/url?id=1&amp;name=aaa</code>, TrueTest record <code className="ph codeph">abc.com</code> as the <code className="ph codeph">application_domain</code>, while the <code className="ph codeph">query_params</code> (<code className="ph codeph">id=1&amp;name=aaa</code>) are stored in the global profile of Katalon Studio.</dd><dt className="dt dlterm">Dynamic URL clustered patterns</dt><dd className="dd">These variables are generated from patterns recognized in dynamic URLs. For example, in the URL <code className="ph codeph">abc.com/orgID/111/projectID/112</code>, TrueTest identifies <code className="ph codeph">orgID</code> and <code className="ph codeph">projectID</code> as dynamic elements and generates global variables accordingly.</dd></dl></div>
<div xmlns="http://www.w3.org/1999/xhtml" className="p">Before executing a test case, TrueTest will prompt you to input the correct values for global variables in Katalon Studio. To do so:<ol className="ol"><li className="li"><p className="p">In the <span className="ph uicontrol">Tests Explorer</span> tab, open the  <span className="ph uicontrol">Profiles</span>  menu and select the global profile you use.</p></li><li className="li"><p className="p">Add the values for the required variables accordingly. In this example, you need to input a value for <code className="ph codeph">query_params</code>.</p><p className="p"><img className="image" width={700} src={useBaseUrl("/ba488cbc-df43-4bac-b4a7-0abd32e63c25/truetest-add-global-values.png")} /></p></li></ol></div>

## Test Case Variables

<p xmlns="http://www.w3.org/1999/xhtml" className="p">In  Katalon Studio, you can find test case variables in the <span className="ph uicontrol">Variables</span> tab, or  in the associated test data files. Test case variables are generated from <strong className="ph b">dynamic objects</strong> that TrueTest detects.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">You can either use the sample value generated for the variables to run the test case immediately, or use another value. Do as follows:</p> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol"><li className="li">Locate the variable in the test case. For example, here we look at <code className="ph codeph">link_productSheetSander_dataTest</code>. <p className="p"><img className="image" width={800} src={useBaseUrl("/065a6058-ed20-4287-91d8-668940dbe9b6/truetest-locate-the-variable.png")} /></p></li><li className="li">In the test case <span className="ph uicontrol">Data Binding</span> tab, find the data file that the variable belongs to, and download that data file.<p className="p"><img className="image" width={850} src={useBaseUrl("/03421175-dedb-4fa0-9e58-bce49f3ca3f8/truetest-find-file-path.png")} /></p></li><li className="li">Open the  file in Excel/Google Sheet to add another value as needed.</li><li className="li">Save/Download the file.</li><li className="li">Import the file back to Katalon Studio as a new data file or override the existing one. For instruction, see <a className="xref" href="/katalon-studio/data-driven-testing/manage-test-data#task-4649">Create an Excel data file</a>. <p className="p"><img className="image" width={600} src={useBaseUrl("/ca148340-750d-11ed-a602-0242cfbc79b5/Excel_2.png")} /></p></li></ol> 

## Function Variables

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Function variables are placed in the <span className="ph uicontrol">Common</span> folder that are called by the corresponding test cases. TrueTest stores them in the test data file associated with the common functions, and   provides sample values for them.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p"><img className="image" width={700} src={useBaseUrl("/59d28ae4-64ff-4165-a31e-e60fe5dd65af/truetest-function-variables.png")} /></p> 
        
<p xmlns="http://www.w3.org/1999/xhtml" className="p">TrueTest detects dynamic objects in the common functions and creates variables for these objects. These variables are important because the functions are reused across multiple test cases.</p> 
        
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Before executing test cases that have function variables, you can either use the sample values from the test data file, or manually enter the  values for these variables in the test data file linked to the common functions.</p>
