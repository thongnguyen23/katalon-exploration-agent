## <a id="task-2650" class="anchor_top_offset"/>View playback log

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">The playback log is a step-by-step account of the test case playback. This functionality serves to verify the accuracy of your chosen test steps and the order. This is different from <a className="xref" href="/katalon-platform/create-tests/create-tests-using-katalon-cloud-studio-beta/execute-katalon-cloud-studio-beta-tests/instantly-run-a-test-case-in-katalon-cloud">running a Katalon Cloud Studio (Beta) test case</a>.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">   <p className="p">To view the playback log:</p> </section> 
<div xmlns="http://www.w3.org/1999/xhtml" className="li step p"><span className="ph cmd">After playback, navigate and click the <strong className="ph b">Log</strong> section just below the test steps, as shown below. <img className="image" src={useBaseUrl("/9c670b40-9f21-11ee-b8c3-0242c7a41fd4/CS_click_Log.png")} alt="Click Log to view the Log viewer." /></span></div>
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">You can now view the playback log. <p className="p">The playback log contains the following information and subsequent timestamps:</p><ul className="ul"><li className="li">       <p className="p">The test run environment, including the browser and OS</p>     </li><li className="li">       <p className="p">The test step execution information and status</p>     </li><li className="li">       <p className="p">Test case status</p>     </li><li className="li">       <p className="p">Playback session status</p>     </li></ul><p className="p">Refer to the following table for the test case status types:</p><table className="simpletable"><colgroup><col style={{width: '50%'}} /><col style={{width: '50%'}} /></colgroup><thead><tr className="sthead">         <th className="stentry" scope="col">Status</th>         <th className="stentry" scope="col">Description</th>       </tr></thead><tbody><tr className="strow">         <td className="stentry"><code className="ph codeph">Passed</code></td>         <td className="stentry">The test case is successfully run with all passing steps.</td>       </tr><tr className="strow">         <td className="stentry"><code className="ph codeph">Failed</code></td>         <td className="stentry">The test case fails to run at least one step.</td>       </tr><tr className="strow">         <td className="stentry"><code className="ph codeph">Incomplete</code></td>         <td className="stentry">The test case is stopped before it finishes running.</td>       </tr></tbody></table></section>
