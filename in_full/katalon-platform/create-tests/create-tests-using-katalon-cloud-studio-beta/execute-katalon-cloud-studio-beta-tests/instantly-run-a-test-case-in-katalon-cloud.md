# <a id="task-9736" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Instantly run a test case in Katalon Cloud

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">Learn how to instantly execute a single Katalon Cloud Studio (Beta) test case without the need to create a test suite.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Instant Run is a feature that allows you to execute Katalon Cloud Studio (Beta) test cases with your preferred test environment. </section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step"><span className="ph cmd">From the Project home screen, go to <span className="ph uicontrol">Tests &gt; Test Cases</span> and select the test case you wish to run.</span></li><li className="li step"><span className="ph cmd">There are three (3) ways you can instantly run a test case. </span><ol type="a" className="ol substeps"><li className="li substep substepexpand"><span className="ph cmd">Hover along the test case, then click the 3-dot icon of a test case in the test case list and click <span className="ph uicontrol">Run</span>. <img className="image" width={700} src={useBaseUrl("/69fb66d0-77ba-11ee-8403-0242c7a41fd4/Hover_and_click_test_case_playback.png")} alt="A test case's dropdown menu in Katalon Cloud Studio." /></span></li><li className="li substep substepexpand"><span className="ph cmd">Alternately, you can open the test case, click the <span className="ph uicontrol">Run</span> button in the test case details view. </span><div className="itemgroup info"><img className="image" width={700} src={useBaseUrl("/69f32970-77ba-11ee-8403-0242c7a41fd4/Open_test_case_and_playback.png")} alt="Open test case and click Run in the test case details view." /></div></li><li className="li substep substepexpand"><span className="ph cmd">Click the <span className="ph uicontrol">Run</span> button right in the Test Editor view. <img className="image" width={700} src={useBaseUrl("/69d95fe0-77ba-11ee-8403-0242c7a41fd4/Click_Run_test_case_in_Editor_view.png")} alt="Instant Run in Editor view." /></span></li></ol></li><li className="li step"><span className="ph cmd">Select the OS configuration you want to run the test case under, and the browser and version: <img className="image" width={500} src={useBaseUrl("/69e19d40-77ba-11ee-8403-0242c7a41fd4/configure_test_case_playback_environment.png")} alt="Configure a test run in Katalon Cloud Studio" /></span></li><li className="li step"><span className="ph cmd">Click on <span className="ph uicontrol">Run Test</span> to begin executing. </span></li><li className="li step"><span className="ph cmd">A pop-up notification will show at the upper right corner confirming your execution.</span></li><li className="li step"><span className="ph cmd">Click on <span className="ph uicontrol">View Run Progress</span> to quickly view your test report. </span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result"><p className="p">A toast notification indicates that the test run is currently in progress, with a link to view the test run progress. </p><p className="p">When clicked, it redirects you to the <span className="ph menucascade"><span className="ph uicontrol">Executions</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Calendar</span></span> tab, which displays the test run in progress:<img className="image" width={750} src={useBaseUrl("/6b7a17a0-7967-11ee-8403-0242c7a41fd4/test_run_in_progress.png")} alt="View test run in progress in Executions > Calendar tab." /> </p><p className="p">Once the test run finishes, it displays a summary of the test results, including the results of the test run (<code className="ph codeph">Passed</code>/<code className="ph codeph">Failed</code>) and other pertinent information such as a link to the test run report.</p><p className="p">Here is an example of a completed test run:<img className="image" width={700} src={useBaseUrl("/aaace002-7968-11ee-8403-0242c7a41fd4/test_run_result_summary.png")} alt="View a summary of your test run results." /><img className="image" width={750} src={useBaseUrl("/dcd9b940-7968-11ee-8403-0242c7a41fd4/test_run_report.png")} alt="Click Details to view the Test Run report." /></p></section>
