title: Integrations in Katalon TestOps
---

Katalon TestOps supports numerous integrations with third-party platforms and functionalities such as project management, test execution frameworks, test scripts migration and CI/CD.

## Codeless Automation Tool

| Product | Description |
| --- | --- |
| [Katalon Studio](/katalon-platform/integrations/codeless-automation-tool/katalon-studio-integration) | Katalon Studio is an automated testing IDE built upon the Selenium framework that enables your team to create and execute tests across diverse applications. |

## CI/CD integrations

| Products | Description |
| --- | --- |
| [AWS CodeBuild](/katalon-platform/integrations/ci-cd/aws-codebuild-integration) | Integrate AWS CodeBuild to upload test reports directly to TestOps. |
| [Azure DevOps](/katalon-platform/integrations/ci-cd/ado-pipeline-integration) | • Run Katalon Studio projects using the **Katalon for Azure DevOps** extension from the Visual Studio Marketplace. [See documentation](/katalon-studio/integrations/cicd-integrations/azure-devops-integration) for more details <br /> • Support uploading test reports to TestOps |
| [GitHub Actions](/katalon-platform/integrations/ci-cd/github-action-integration) | • Automate Katalon Studio projects execution using [Katalon Studio GitHub Action](https://github.com/marketplace/actions/katalon-studio) on GitHub marketplace. [See documentation](/katalon-studio/integrations/cicd-integrations/katalon-studio-github-action) for more details. <br /> • Support uploading test reports to TestOps |
| [Docker](/katalon-platform/integrations/ci-cd/docker-integration) | • See how to [create a Docker Test Environment with a compatible Agent in Katalon TestOps](/katalon-platform/execute/test-execution-with-testops/set-up-docker-test-environments-for-testops). <br/> • Support uploading test reports to TestOps |
| [Gitlab CI](/katalon-platform/integrations/ci-cd/gitlab-ci-integration) | • Integrate your Katalon Studio project and run your GitLab CI jobs in a Docker container built from the Katalon Studio Docker image. See [documentation](/katalon-studio/integrations/cicd-integrations/gitlab-integration) for more details. <br /> • Support uploading test reports to TestOps |
| [Katalon CLI](/katalon-platform/integrations/ci-cd/katalon-cli-integration) | The Katalon Command-line Interface (CLI) Docker Image allows you to trigger test execution from existing test schedules on TestOps |
| [Report Uploader](/katalon-platform/integrations/ci-cd/report-uploader-integration) | Katalon Report Uploader is a utility to upload reports to Katalon TestOps. The utility supports JUnit, Katalon Studio, and Katalon Recorder report format |
