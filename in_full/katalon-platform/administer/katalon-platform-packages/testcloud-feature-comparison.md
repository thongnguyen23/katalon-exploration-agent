The article below provides information on the available subscription plans for **TestCloud**.

## **Overview**

Katalon Platform is currently offering two plans:

- TestCloud Trial
- TestCloud Per Session

### TestCloud Trial

TestCloud Trial allows all new users to explore a test automation environment that allows you to execute tests on most standard browsers and operating systems on the cloud. This plan offers a free trial of 3 TestCloud sessions for Desktop Browser Testing, valid for 30 days starting from the date your TestOps organization is created.

Once the trial ends, you will need to purchase the TestCloud per Session plan to continue to use the TestCloud session.

### TestCloud per Session

Katalon TestCloud per Session is best for large organizations and teams with stable testing plans and long-running tests.

This plan currently defines 4 types of sessions of **Automation** and **Live** environments:

- **Desktop Browser Testing**: A cloud-based environment for seamless automated testing across various desktops with comprehensive browser coverage.
- **Desktop & Mobile Browser Testing**: A cloud-based environment for automated cross-browser testing on desktops and extending to real Android and iOS devices.
- **Mobile Native App Testing**: Real mobile devices for efficient and reliable automated testing of your native mobile applications.
- **Live Testing**: Manually test web and mobile apps on real devices with support for all TestCloud environments (desktop browsers, mobile browsers, and mobile native applications). 

The per Session plan gives you unlimited testing duration per session. One session allows you to run one sequence of tests, for as long as you need.

The number of sessions you purchase is the maximum number of parallel tests you can execute. Therefore, you can purchase more TestCloud sessions to increase the number of parallel test executions.

You can view your usage quota and manage your TestCloud per Session subscription on Katalon TestOps. For detailed information on how to make a purchase, you can refer to this document: [Purchase Katalon subscriptions](https://docs.katalon.com/katalon-platform/administer/administration-tasks/payment-and-subscription/purchase-katalon-subscription#task-q39m18ta).

#### Plan bundle

Live Testing is available to be purchased as a standalone solution, or as an add-on to existing TestCloud subscription **at no additional cost**. 
    - For this specific case, Automation and Live environments will share the same pool of sessions. This means if you purchase 10 TestCloud desktop licenses, you will be able to run a maximum of 10 parallel sessions on Desktop, regardless of whether they are Automation or Live.
    
| **Plan** | **Automation Environments** | **Live Environments** |
| ---- | ----------------------- | ----------------- |
| Live Testing | N/A | Desktop + mobile browsers + mobile native apps |
| Desktop Browser | Desktop browsers only | Desktop browsers only |
| Desktop and Mobile Browser | Desktop & mobile browsers | Desktop browsers only |
| Mobile Native App | Mobile native apps only | Mobile browsers + mobile native apps |
