# <a id="task-636" class="anchor_top_offset"/><a id="ariaid-title1" class="anchor_top_offset"/>Remove a Member from a Project

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This document shows you how to remove a Member from a single Project. </p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li"><p className="p">Make sure you are a Project Admin or possess the relevant permissions. Go to <a className="xref" href="/katalon-testops/administration-and-licensing/manage-systems/permissions/about-roles">roles</a> or <a className="xref" href="/katalon-testops/administration-and-licensing/manage-systems/permissions/about-permissions">permissions</a> for more information or learn how to <a className="xref" href="/katalon-testops/administration-and-licensing/manage-administrators/assign-or-unassign-project-administrators">assign a Project Admin here</a>. </p></li></ul></div>
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Remove a Member by going to <span className="ph menucascade"><span className="ph uicontrol">Admin Settings</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Project</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Members</span></span> and clicking on the <span className="ph uicontrol">Remove</span> icon within their row. </section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph menucascade"><span className="ph uicontrol">Admin Settings</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Project</span></span>. You can find Admin Settings at the upper right corner of the page, indicated by a cog icon.<br/>The <span className="ph uicontrol">General</span> tab appears by default. </span></li><li className="li step stepexpand"><span className="ph cmd">Go to the <span className="ph uicontrol">Members</span> tab. The member directory is displayed, with all Members listed.</span></li><li className="li step stepexpand"><span className="ph cmd">Click on the <span className="ph uicontrol">Remove</span> icon that's within the row of the Member you would like to remove from the Project.
