This shows you what the Test Case Execution Status Report is and how to use it.

## Prerequisites

<Reusable />

---

This report combines three powerful visualizations:

- A pie chart that displays test cases organized by execution result (Passed, Failed, etc.), showing both counts and percentages for each status category. You can use this to quickly assess your overall test quality and identify problematic areas.

- A comparative metrics panel that breaks down test success rates by execution methodology (Manual versus Automated). This visualization shows you the number of passing test cases and their corresponding pass rate percentages, helping you evaluate the effectiveness of your different testing approaches.

- A comprehensive list view that presents all test cases with their associated metadata and execution information. You can use this table to drill down into specific test assets and examine their details.

This comprehensive view allows you to track test execution metrics. Find it in **Reports** > **All Reports** > **Test Case Execution Status**.

## View Test Case Execution Status

1. Go to **Reports** > **All Reports** > **Test Case Execution Status**.

<br/>

<img src="https://tw-cdn.katalon.com/katalon-testops/Reports/All Reports/Report Types/Report Test Case Execution Status.png" alt="The Test Case Execution report page in Katalon TestOps." width="1080"/>

<br/>

2. Enter search parameters to filter for specific data. You can:
- Select a date range

3. Click **Apply** to segregate the data or **Reset** to clear all filters.
