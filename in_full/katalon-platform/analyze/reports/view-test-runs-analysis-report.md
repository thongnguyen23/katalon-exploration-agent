<Reusable />

---
Use this report to analyze test run completion status, execution results, and overall success rates. You can also identify trends in test run performance.

## View Test Runs Analysis

1. Go to **Reports** > **All Reports** > **Test Run Status Report**. The page displays the Test Run Status Summary chart and the [Test Run list](/katalon-platform/analyze/reports/test-runs). 

<br/>

<img src="https://tw-cdn.katalon.com/katalon-testops/Reports/All Reports/Report Types/Test Runs Analysis June 4 2025.png" alt="The Test Run Report page in Katalon TestOps." width="1080"/>

<br/>

2. Enter search parameters to filter for specific test runs. You can: 
- Input dates
- Select release: Allows you to filter for test run based on its [associated release](/katalon-platform/plan/about-the-sprint-release-timeline).
- Select **Profile**.
- Click on **+ Add more** to view more filters. They are:
    - Select Test Suite
    - Select Test Suite Collection
    - Select Test Run Status
    - Select Executor
    - Select Build Label
    
3. Click on **Apply** to narrow your search or **Reset** to reset the page’s results.
